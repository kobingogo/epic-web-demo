# 🌊 FLUID · 流体之境

一个**纯手写、零依赖、单 HTML 文件**的 WebGL 实时流体模拟 demo。
在 GPU 上求解 Navier–Stokes 方程，并叠加辉光、液态高光、胶片颗粒和暗角。

## ✨ 玩法

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 | 拖出发光的烟雾尾迹 |
| 按住拖拽 | 更强的力，颜料更浓 |
| 双击 | 💥 在该点径向爆裂 |
| `Space` | 屏幕中心 BIG BANG |
| `C` | 切换调色板（彩虹 / 霓虹 / 烈焰 / 深海 / 极光） |
| `A` | 自动漂流（不操作时三股喷流沿利萨如曲线自己画画） |
| `B` | 辉光开关 |
| `M` | 🎤 音乐律动：用麦克风采样，检测到低音节拍就炸开 |
| `P` | 冻结时间 |
| `S` | 📸 截图保存 |

支持多点触控，手机上也能玩。

## 🧪 技术要点

- **流体求解**：涡度约束（Vorticity Confinement）→ 散度 → 压力 Jacobi 迭代 ×20 → 梯度相减 → 半拉格朗日平流
- **双缓冲 FBO**（ping-pong），用半精度浮点纹理；不支持线性过滤时自动退回手动双线性插值
- **辉光（Bloom）**：软阈值预过滤，接 8 级降采样和加法回采样
- **着色**：用颜料密度梯度重建法线，做漫反射和镜面高光，看起来像液态金属
- **音频**：Web Audio `AnalyserNode` 做 FFT，按低音能量的突变检测节拍

## 🚀 运行

直接用浏览器打开 `index.html` 就行。也可以开启 GitHub Pages（Settings → Pages → main / root）在线访问。
